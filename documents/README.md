# Documents du projet Datasea

Cette rubrique rassemble les livrables du projet pédagogique de sécurisation de l’infrastructure DATASC.SEA.

- **Rapport-Projet-Datasea.pdf** — rapport de projet.
- **Presentation-Projet-Datasea.pdf** — version consultable de la présentation.
- **Presentation-Projet-Datasea.pptx** — version modifiable de la présentation.
- **Schema-Architecture-Datasea.pdf / .png / .svg** — exports du schéma d’architecture cible.
- **Schema-Architecture-Datasea.drawio** — fichier source modifiable dans diagrams.net / Draw.io.

La version publique de la présentation intègre le schéma d’architecture révisé directement dans la diapositive dédiée. La diapositive qui ne contenait qu’un lien vers un fichier Excel externe non fourni a été retirée ; la synthèse des risques figure toujours dans la présentation.
